# Loanword

An Obsidian plugin for learning Korean and Chinese inside the notes you already read every day.

- A daily review appears in front of you until it's done.
- A few English words in your notes show up as Chinese or Korean (Live Preview). Click one and guess what it means.
- Spaced repetition (Leitner boxes), one learning profile shared across vaults.
- Fully offline. It never modifies your notes.

Status: in development. See the issues.
